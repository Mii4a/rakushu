# らくしゅう料金改定提案（2026-06-23）

## 1. 結論

おすすめは、こうです。

- Free: 無料のまま残す。ただし「お試し回数」を明記する
- Starter: 580円 → 480円
- Plus: 1,480円 → 980円
- Pro: 2,980円 → 1,980円

この形にすると、

- Starter は `yagish 550円/30日` や `カチメン 600円/月` より入りやすい
- Plus は `AI面接 600円 + 企業研究 780円 = 1,380円` の低価格帯より安く、束ね買いより得になる
- Pro は、個別に安い有料機能を全部足した `約1,930円` に近い価格に落ちるので、今の 2,980円 より納得感が高い

計算根拠:

- 履歴書系の低価格課金代表: 550円/30日（yagish）
- AI面接の低価格個人課金代表: 600円/月（カチメン）
- 企業研究の明確な個人課金代表: 780円（企業研究AI）
- 3カテゴリ低価格合算: 1,930円

## 2. 競合比較から見えた事実

### 2-1. 履歴書添削・作成系

- 多くが無料
- 明確な個人課金でも 500〜550円級が中心
- つまり「履歴書AIがあるから月1,000円超」は通しにくい

### 2-2. AI面接系

- 個人向けは無料か低額サブスク
- 明確な個人課金で見やすいのは 600円/月
- 企業向け高額SaaSも多いが、これは B2B 価格なので学生向け値付けの基準にはしにくい

### 2-3. 企業研究系

- 学生向けは無料が多い
- 単機能の明確な個人課金で見えたのは 780円
- ただし多くは無料で集客して周辺収益化している

### 2-4. 無料枠の勝負は「有無」より「明示」

競合の多くは無料だが、無料で何回使えるかは曖昧です。ここは逆にチャンスです。

らくしゅうは、

- 企業研究: 初回何回まで無料
- AI面接: 初回何セッションまで無料
- 履歴書下書き: 初回何件まで無料

を明記すると、比較しやすさで勝ちやすいです。

## 3. 現行料金の評価

現行:

- Starter: 580円
- Plus: 1,480円
- Pro: 2,980円

評価:

- Starter は悪くないが、競合より“少しだけ安い”に留まる
- Plus は機能束ね価値を出せば十分戦えるが、1,480円だと「まず試す」心理にはまだ重い
- Pro は高い。個人課金の相場感から見ると、よほど強い継続価値が見えない限り離脱しやすい

特に今の Pro は、

- 学生が単月で払う額としては高め
- 競合が無料または低額なので比較で不利
- らくしゅうの核価値である「求人採点」「基準共有」がまだ市場で常識化していない段階では、説明コストが高い

ので、価格で迷わせやすいです。

## 4. らくしゅうの勝ち筋に合う料金設計

重要なのは、らくしゅうを「履歴書AI」「面接AI」「企業研究AI」のどれか単体として売らないことです。

らくしゅうの核は、

- 求人を貼る
- 採点する
- 比較する
- 判断基準を自分用に育てる
- その基準を共有する

です。

つまり、課金の軸は「AI機能の数」ではなく、

- 就活の判断作業をどこまで一気通貫で前に進められるか
- 自分の基準をどこまで育てられるか
- 保存・比較・共有をどこまで解放するか

に置いた方がいいです。

## 5. 推奨プラン案

## Free

狙い:
- とにかく初回価値を出す
- 無料競合だらけの中で、使わず離脱を防ぐ

推奨内容:
- 求人保存: 10〜20件
- 求人採点: 週3〜5回
- 企業研究: 1回
- AI面接: 1セッション
- 履歴書ワークスペース: 1件の下書き
- 公開基準の閲覧: 一部可

ポイント:
- いまの Free は AI価値の入口が弱い
- 完全遮断より「少し体験させる」方が転換しやすい
- 特に AI面接 1回無料 は訴求が強い

## Starter 480円

狙い:
- 最初の有料化ハードルを極限まで下げる
- `550円` `600円` の競合より買いやすくする

推奨内容:
- 企業研究を継続利用可
- 求人採点の月次枠を増やす
- 履歴書下書き保存を解放
- AI面接は対象外、または月1〜2回までの軽量枠

向いている人:
- まず求人比較を回したい
- 面接前より、求人選びの段階が主目的

## Plus 980円

狙い:
- 主力プランにする
- 企業研究 + AI面接 + 採点基準育成の一式をここに集約する

推奨内容:
- AI面接を本格解放
- 企業研究を継続利用可
- 自分用基準の保存・編集を解放
- 通勤時間自動計算を含める
- 月次AI枠は十分に持たせる

向いている人:
- 一般的な就活ユーザーの本命
- 面接対策まで回したい人

この価格の強み:
- 個別低価格機能の合算 1,380円 より安い
- 「就活AIを別々に契約するより、らくしゅう1つの方が得」が作れる

## Pro 1,980円

狙い:
- ヘビーユーザー向けに残す
- ただし“高すぎて比較負けする価格”は避ける

推奨内容:
- 比較ページフル解放
- 公開基準の作成・公開・統計確認
- 履歴書ワークスペースの保存・再利用を強化
- AI面接 / 企業研究 / 求人採点の上限を大きく広げる

向いている人:
- 長めに就活する人
- 自分の基準を公開・改善したい人
- 大量に比較しながら判断したい人

## 6. 価格以外で必須の改定

### 6-1. 無料枠の回数明記

これはかなり大事です。

競合は無料でも、回数が見えません。らくしゅうは逆に、こう書く方がいいです。

- 無料で企業研究 1回
- 無料でAI面接 1セッション
- 無料で求人採点 週5回

この「何回まで」が明記されているだけで、比較表で強いです。

### 6-2. 主力プランの一本化

今後の訴求は Plus 中心に寄せるのがいいです。

理由:
- Starter は入口
- Pro は一部の人だけ
- 一番売りたいのは Plus

Pricing ページでも、

- Plus を標準
- Plus で 企業研究 + AI面接 + 自分用基準 を全部使える
- 「まずこれで十分」をはっきり出す

のがよいです。

### 6-3. AI単機能訴求から、判断作業台訴求へ寄せる

避けたい訴求:
- AI履歴書もできます
- AI面接もあります
- AI企業研究もあります

寄せたい訴求:
- 求人を採点して比較できる
- 自分に合う条件を基準化できる
- 企業研究と面接準備までつながる

競合は AI単機能の無料ツールが多いので、同じ土俵に乗ると消耗しやすいです。

## 7. 実装するなら変える場所

主要変更箇所:

- `src/lib/plans.ts`
  - `PLAN_MARKETING` の価格
  - 必要なら `PLAN_LIMITS` の無料枠 / AI機能開放条件
- `src/app/pricing/page.tsx`
  - 価格表示文言
  - 無料枠や主力プラン訴求
  - Free のお試し回数の見せ方
- Stripe 側
  - `STRIPE_PRICE_STARTER`
  - `STRIPE_PRICE_PLUS`
  - `STRIPE_PRICE_PRO`
  - 新価格の Price を Stripe で作り直す必要あり
- 必要なら法務文言
  - 返金・キャンセルポリシー
  - 特商法表記

注意:
- checkout 実装は price ID を env で切っているので、コード修正だけでは決済額は変わりません
- Stripe 側の Price 差し替えが必要です

## 8. すぐやるならおすすめ順

1. まず料金方針を `480 / 980 / 1980` で確定する
2. Free のお試し回数を決める
3. `src/lib/plans.ts` と `src/app/pricing/page.tsx` を更新する
4. Stripe で新 price を作る
5. env を差し替える
6. Pricing ページ文言と決済導線を通し確認する

## 9. 最終提案

僕ならこうします。

- Free: お試し回数を明記して AI入口を少し開ける
- Starter: 480円
- Plus: 980円 を主力化
- Pro: 1,980円 に下げる

理由はシンプルで、

- 無料競合が多い市場で、初回課金ハードルを下げられる
- Plus を「個別契約より安い全部入りの本命」にできる
- Pro の価格不信を減らせる
- らくしゅうの本質である「求人採点と基準共有」に会話を戻せる

逆に、今の 2,980円 Pro を維持したまま勝つには、現時点では説明コストが高すぎます。まずは価格で迷わせない方がいいです。
