# らくしゅう / 企業研究レポートUI 実装プロンプト

らくしゅうの企業研究画面 `/company-research` または既存の企業研究結果画面について、添付モックを基準にUIを実装してください。

## 目的

現在、らくしゅうAIが企業研究結果をチャット本文内に直接展開しています。
これをChatGPTのDeep Researchに近い体験へ変更し、以下の2状態を実装してください。

- モーダル非表示時
- モーダル表示時

企業研究そのものは、就活向けに短く要約するだけではなく、広範囲な企業情報を長文でまとめる「総合企業調査レポート」として扱ってください。
ユーザーはチャット上でレポートの一部を確認し、必要に応じてモーダルで全文を閲覧します。

## 参照モック

- `03-company-research-result-modal-hidden.png`
- `03-company-research-result-modal-open.png`

画面全体のレイアウト、左右サイドバー、余白感、白 / 薄いグレー / 黒を中心にした配色、ボーダー、角丸、文字サイズのバランスはモックに合わせてください。

## 共通レイアウト

左側には既存のグローバルサイドバーを維持してください。

表示項目は以下です。

- ダッシュボード
- 求人一覧
- 求人チェッカー
- 企業研究
- レジュメAI
- AI面接
- チェック基準
- みんなで知恵袋
- 設定

企業研究を選択状態にしてください。

中央上部には以下を配置してください。

- ページタイトル「企業研究」
- 補足文
- 「一覧に戻る」
- 「共有する」
- 三点メニュー

右側には既存の「企業研究の履歴」サイドバーを維持してください。

履歴カードには企業名 / 時刻または日付 / 保存済み表示 / ブックマークアイコンを表示してください。

## チャット部分

ユーザー発言例

「<URL>について詳しく調べてください。」

その下に、らくしゅうAIの回答を表示してください。

例

「サイバーエージェント株式会社<URL>について、公開情報をもとに調査を行い、レポートを作成しました。
以下のレポートをご確認ください。」

この回答の下に企業分析レポートのプレビューカードを表示してください。

## モーダル非表示時

レポートカードのタイトルは以下です。

「サイバーエージェント 企業分析レポート」

カード内では、単なる要約カードではなく、長文レポートの冒頭をプレビューできるようにしてください。

表示構造は以下のような階層にしてください。

総合サマリー
本文

企業の基本情報と設立背景

企業名および法的地位
本文

設立年月日と創業の経緯
本文

事業内容とビジネスモデル
本文

本文は箇条書きではなく、2〜4文程度の自然な日本語の文章形式にしてください。

プレビューカードは、レポート本文を複数段落読める高さを確保してください。
ただし全文は表示せず、カード下部で続きがあることが分かるようにしてください。

カード下部には以下を表示してください。

- 約24ページ
- 図表 / グラフ約18
- 最新情報を反映
- 「レポートを開く」ボタン

「レポートを開く」を押すとモーダル表示状態へ遷移してください。

## モーダル表示時

画面全体に半透明のオーバーレイを表示し、その上に大きなレポート閲覧モーダルを中央配置してください。

モーダルは画面の大部分を占めるサイズにし、背景のUIは暗く見える程度に残してください。

モーダル上部には以下を表示してください。

- ドキュメントアイコン
- 「サイバーエージェント 企業分析レポート」
- 生成日時
- 閉じるボタン

モーダル内部は左側に目次、右側に本文の2カラム構成にしてください。

左側の目次は以下を想定してください。

- エグゼクティブサマリー
- 企業の基本情報と設立背景
- 事業内容
- 業界 / 競争環境
- 組織 / 人材
- 財務 / 業績
- 成長戦略
- 従業員評価
- 就活への応用

現在表示中のセクションは背景色で選択状態を示してください。

モーダル本文は、箇条書きを中心にせず、長文の調査レポートとして読める文章形式にしてください。

大見出し → 小見出し → 長文解説の階層構造を基本とします。

例

企業の基本情報と設立背景

企業名および法的地位

サイバーエージェント株式会社は、東京都渋谷区宇田川町に本社を構える東証プライム上場企業です。1998年の創業以来、「21世紀を代表する会社を創る」をビジョンに掲げ、インターネットを軸に複数の事業を展開しています。

設立年月日と創業の経緯

1998年3月18日、藤田晋氏により設立されました。創業当初はインターネット広告代理事業からスタートし、その後、自社メディアやゲーム事業へと拡大しました。

続けて以下のようなセクションを文章形式で表示してください。

- 事業内容とビジネスモデル
- 業界 / 競争環境
- 組織構造と人事制度
- 財務 / 業績の概況
- 成長戦略
- 従業員評価
- 就活への応用

「就活への応用」では、ES / 志望動機 / 面接で使える観点を文章形式で説明してください。

モーダル左下には「PDFでダウンロード」ボタンを配置してください。

モーダル下部には以下の注意書きを表示してください。

「本レポートは公開情報をもとにAIが作成した参考情報です。最新情報は必ず公式サイト等でご確認ください。」

## インタラクション

- 「レポートを開く」でモーダルを開く
- 右上のXでモーダルを閉じる
- モーダル外クリックでも閉じられる
- Escapeキーでも閉じられる
- モーダル表示中は背景スクロールを禁止する
- モーダル本文は内部スクロール可能にする
- 左側の目次を押すと該当セクションへスクロールする
- 現在読んでいるセクションに応じて目次のアクティブ状態を更新する
- 開閉アニメーションは150〜250ms程度
- オーバーレイはフェード
- モーダルは軽いフェード + スケールで表示する

## チャット下部

既存の質問入力欄は維持してください。

プレースホルダー例

「企業について質問してみましょう  例: 最新のIR情報は？ 年収は？ など」

追加質問では、初回レポートとは異なり、質問内容に応じて箇条書きや短い回答も許容します。

## 実装方針

既存プロジェクトがNext.js / React / TypeScript / Tailwind CSSで構成されている場合は、その既存構成に合わせて実装してください。

推奨コンポーネント分割

- `CompanyResearchPage`
- `ResearchChatMessage`
- `ResearchReportPreviewCard`
- `ResearchReportModal`
- `ResearchReportTableOfContents`
- `ResearchHistorySidebar`
- `NextStepCard`

レポート本文データはUIに直接ハードコードせず、セクション配列として管理してください。

例

```ts
type ResearchSection = {
  id: string
  title: string
  subsections?: {
    id: string
    title: string
    content: string[]
  }[]
}
```

プレビューは同じレポートデータの先頭部分だけを利用してください。

モーダルとプレビューで別々の文章データを持たないようにしてください。

## 重要

- 既存の左サイドバーと右履歴サイドバーの見た目を崩さないでください。
- レポートは箇条書き中心にしないでください。
- 初回生成レポートは「総合企業調査レポート」として長文にしてください。
- チャット内では全文を直接展開せず、複数段落のプレビュー + モーダル全文表示にしてください。
- モックにある情報密度と余白感を再現してください。
- PC向け1920x1080相当の画面を優先して実装してください。
- モーダル表示中も背後の画面構造が分かる程度にオーバーレイ透明度を調整してください。
