## 目的

現在の /ai-interview は縦に情報が伸びており、ユーザーがスクロールしながら回答/確認する必要があります。これを、1画面内でAI面接の流れが分かる固定レイアウトに変更してください。

左の既存サイドバーは維持し、右側に第2サイドバーとしてセッション履歴を追加してください。中央は面接回答に集中できるようにし、設定カードは削除して、初期設定モーダルに移してください。

## 画面レイアウト

全体は3カラム構成にしてください。

左カラムは既存の第1サイドバーです。ロゴ、メニュー、選択中のAI面接、下部の案内カードは既存デザインに合わせて維持してください。左サイドバーはハンバーガーボタンで開閉できるようにしてください。

中央カラムはAI面接のメイン体験です。画面高さ内に収まりやすいよう、カードの余白を抑え、縦スクロールをなるべく発生させないでください。

右カラムは第2サイドバーです。タイトルは セッション履歴 とし、練習セッションの履歴カードを縦に表示してください。第2サイドバーは独自にスクロール可能にしてください。一定以上スクロールしたら未取得の過去セッションを追加読み込みできる構造にしてください。UI上は下部に スクロールすると過去のセッションが読み込まれます という案内を表示してください。右サイドバーもハンバーガーボタンで開閉できるようにしてください。

## 削除するもの

現在上部にある 面接の種類 / 想定企業 / 質問セット の設定カードは削除してください。設定変更は上部の 設定を変更 ボタンから初期設定モーダルを開く形にしてください。

テキストで入力 ボタンは削除してください。回答方法は音声のみにしてください。

右側に現在ある 今回のフィードバック / よかった点 / 次に直す点 / 次に聞かれそうな質問 などのカードは削除し、右側はセッション履歴専用にしてください。

## 録音ステート

録音前:
- 緑のマイクボタン
- クリックして録音を開始
- 回答プレビューは空状態

録音中:
- マイクボタンを赤色に変更
- 波形アニメーションを表示
- 録音中 00:38 のような経過時間を表示
- もう一度クリックで録音を終了 と表示
- 回答プレビューにリアルタイム文字起こし中の内容を表示

録音終了後:
- 自動で文字起こし処理に移行
- マイクアイコンをローディングリングに変更
- 文字起こし中... と表示
- 録音データをテキストに変換しています と表示

文字起こし後:
- AI評価処理に移行
- AIらしいアイコンとローディングリングに変更
- AIが評価中... と表示
- 回答内容を分析してフィードバックを生成しています と表示
- 回答プレビューには確定した文字起こしを表示

処理完了:
- 緑のチェックマークを表示
- 処理が完了しました と表示
- フィードバックを見る ボタンを表示

## フィードバックモーダル

選択カテゴリ内の質問をすべて回答し終えたら、カテゴリ単位のフィードバックモーダルを表示してください。

例として 自己紹介 の場合、自己紹介してください と AI生成の追加質問 の2問が終わった後に表示します。

モーダルには以下を表示してください。

- カテゴリ名と AI評価フィードバック
- 2/2問 回答完了 のような完了バッジ
- 回答した質問一覧
- 各質問の回答要約
- 総合評価 4.3 / 5.0 のようなスコア
- よかった点
- 改善ポイント
- 次に意識したいこと
- 次に聞かれそうな質問
- 閉じる ボタン
- 次のカテゴリへ ボタン

## セッション履歴

セッションは練習1回ごとに保存してください。

履歴カードに表示する項目は以下です。

- ステータス: 完了 は青、進行中 は黄色
- 設定セット名
- シナリオ名
- 質問数
- 所要時間
- 最終更新または完了日
- 詳細へ進む矢印

右サイドバーは独立スクロールにしてください。IntersectionObserver などで下部までスクロールしたら追加読み込みする構造にしてください。まずはモックデータで構いませんが、将来API接続しやすいように型を分けてください。

## 実装方針

既存のデザインシステムに合わせ、Tailwind CSS の既存色、角丸、ボーダー、シャドウを利用してください。
ただし、既存のコンポーネントを優先して使用する方針を残すがあまり、モックにない既存機能で補ってしまい、モックとは異なった画面ができてしまう。playwrightとモック画像の比較を行い、モック画像に表示されていない箇所は削除すること。

状態管理は以下のようなステートを想定してください。

- setupStep
- setupModalOpen
- leftSidebarOpen
- rightSidebarOpen
- selectedScenarioType
- selectedCategories
- currentCategoryIndex
- currentQuestionIndex
- recordingState: idle / recording / transcribing / evaluating / completed
- transcript
- sessionHistory
- feedbackModalOpen

録音処理、文字起こし、AI評価は既存APIが未完成であればモックで動作してください。録音開始から録音中、停止、文字起こし中、AI評価中、完了までのUI遷移を確認できるようにしてください。
